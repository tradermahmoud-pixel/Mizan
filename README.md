# ميزان

نظام المبيعات والمخازن والموظفين — نسخة مستقلة (Node.js + PostgreSQL).

## التشغيل
متغيرات البيئة:
- `DATABASE_URL` — رابط قاعدة بيانات PostgreSQL
- `ADMIN_USER`, `ADMIN_PASSWORD`, `ADMIN_NAME` — حساب المالك (يُنشأ أول مرة فقط)

```
npm install
npm start
```

البيانات نفسها لا تُحفظ في هذا المستودع. النسخ الاحتياطي والاسترجاع من شاشة الإعدادات داخل البرنامج.

## أكتر من عميل (Multi-tenant)
كل شركة مشتركة ليها بياناتها ومستخدمينها لوحدها في نفس قاعدة البيانات (عمود `tenant` في كل الجداول).
- البيانات الموجودة قبل التحديث بقت تبع الشركة الرئيسية `main`.
- مالك الشركة الرئيسية بس يقدر يدير العملاء من `/tenants` (إضافة شركة فاضية، إيقاف، تاريخ انتهاء الاشتراك).
- `TENANTS_INIT` (اختياري): JSON لإنشاء شركات أول تشغيل، مثال:
  `[{"id":"alhayah","name":"الحياة","ownerUsername":"hayah","ownerPassword":"..."}]` — بيتجاهل أي شركة موجودة، وتقدر تمسحه بعد أول تشغيل.
- `MAIN_TENANT_NAME` (اختياري): اسم الشركة الرئيسية في صفحة العملاء.
- إعدادات `AI_*` في السيرفر بتشتغل للشركة الرئيسية بس؛ كل عميل يحط مفتاحه من الإعدادات.
