# ميزان

نظام المبيعات والمخازن والموظفين — نسخة مستقلة (Node.js + PostgreSQL).

## التشغيل
متغيرات البيئة:
- `DATABASE_URL` — رابط قاعدة بيانات PostgreSQL
- `ADMIN_USER`, `ADMIN_PASSWORD`, `ADMIN_NAME` — حساب المالك (يُنشأ أول مرة فقط)

```
npm install
npm start
```

البيانات نفسها لا تُحفظ في هذا المستودع. النسخ الاحتياطي والاسترجاع من شاشة الإعدادات داخل البرنامج.
